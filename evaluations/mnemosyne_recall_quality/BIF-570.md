# BIF-570 Mnemosyne selective prefetch regression

BIF-570 adds a gated selective prefetch path on top of the BIF-568 trusted explicit-recall baseline.

## Gate

Selective prefetch remains **off by default**. It only runs when `$HERMES_HOME/mnemosyne/config.json` contains:

```json
{
  "selective_prefetch_enabled": true
}
```

## Safety invariants

- suppressed memories never prefetch
- stale/deprecated/legacy/outdated memories never prefetch by default
- sensitive markers such as secret/token/password/API key/credential never prefetch by default
- irrelevant low-overlap queries return no prefetch context
- invalid config fails closed
- formatted context includes memory IDs/sources so Biff can explain memory influence
- current user instructions remain authoritative
